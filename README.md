# Rongjie Zhang — Academic Personal Website

Static academic website ready for GitHub Pages, for GitHub user **zhangrongjiethu**.

**Intended site:** https://zhangrongjiethu.github.io/ — becomes live once GitHub Pages is deployed.
**GitHub profile:** https://github.com/zhangrongjiethu

## Publish

1. Create a **public** GitHub repository named **zhangrongjiethu.github.io**.
2. Upload this ZIP's **contents** (not the ZIP itself) to the root of the repository, keeping `index.html` at root.
3. Under Settings → Pages, select **Deploy from a branch**, then **main** / **/(root)**.
4. Open https://zhangrongjiethu.github.io/ after GitHub Pages has published.
